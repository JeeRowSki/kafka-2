################################# Описание

Приложение на Python и Faust Streaming обрабатывает поток сообщений Kafka: отклоняет сообщения от заблокированных отправителей и маскирует запрещённые слова звёздочками. Правила обновляются динамически через отдельные Kafka-топики. Состояние хранится в таблицах Faust с локальным хранилищем RocksDB и changelog-топиками Kafka.

В Kafka используются следующие топики:

 `messages`  Входящие сообщения 
 `blocked_users`  События блокировки и разблокировки отправителей 
 `banned_words`  События добавления и удаления запрещённых слов 
 `filtered_messages`  Сообщения, прошедшие фильтрацию 

############################# Основные компоненты

- **`Message`** (`models.py`) — сообщение с полями `message_id`, `sender_id`, `recipient_id`, `text`.
- **`BlockEvent`** (`models.py`) — событие с полями `user_id`, `blocked_user_id`, `action` (`block` / `unblock`).
- **`WordEvent`** (`models.py`) — событие с полями `word`, `action` (`add` / `remove`).
- **`normalize_word()`** (`filters.py`) — удаляет пробелы по краям слова и нормализует регистр.
- **`censor_text()`** (`filters.py`) — заменяет запрещённые слова звёздочками с учётом границ слов, без учёта регистра.
- **`process_blocks()`** (`app.py`) — обновляет список блокировок конкретного получателя в `blocked_users_state`.
- **`process_words()`** (`app.py`) — обновляет `banned_words_state`.
- **`process_messages()`** (`app.py`) — проверяет блокировки, маскирует слова и публикует разрешённые сообщения в `filtered_messages`.

Сообщение от заблокированного отправителя **не публикуется** в выходной топик. Запрещённые слова в разрешённых сообщениях заменяются звёздочками; исходное сообщение в `messages` при этом не изменяется.

########################################### Требования и запуск

- Docker и Docker Compose.
- Доступный Kafka-кластер с брокерами `kafka-0:9092`, `kafka-1:9092`, `kafka-2:9092`.
- Docker-сеть **`kafka-lab_kafka-net`**, к которой подключены Kafka и приложение.

**Важно:** текущий `compose.yml` запускает обработчик Faust, а не весь Kafka-кластер. Kafka развернута в проекте `kafka`.
